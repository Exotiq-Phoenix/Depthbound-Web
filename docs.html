01 / ORIENTATION

What is Depthbound?

Depthbound is a privately developed Unity action RPG prototype focused on interconnected gameplay systems. Its current status is private alpha, meaning mechanics and structure can change significantly.

ALPHA DISCLAIMER

Not every feature described on this website is currently playable. Pages identify prototypes, active work and future designs wherever practical.

02 / SYSTEM REFERENCE

Game systems

Movement and combat +
Third-person movement, basic melee, blocking and player resources have prototype implementations. Animation blending, loadout combinations and encounter depth continue to evolve.
Dungeon generation +
Modules use connector and layout constraints; seeded generation and validation are under active development. Details can change while progression reliability is improved.
Progression and Arcana +
Core resource and progression foundations exist. The expanded construct-driven magic system is a long-term design direction with experimental foundations.
Player interface +
V7 source code introduces adaptive HUD and contextual interaction foundations. The wireframes presented here are design studies and do not establish complete in-game parity.

04 / QUESTIONS

Frequently asked

Can I download Depthbound today? +
No publicly downloadable build is listed in the provided release manifest. The downloads page will display real links only when the manifest contains published URLs.
Are the UI images screenshots of the game? +
No. The illustrated wireframes are concept/design studies used to guide development and should not be interpreted as verified gameplay captures.
Is everything on the roadmap implemented? +
No. The roadmap separates foundations, active work and longer-term aspirations.
Is the project open source? +
The public website repository is linked in the footer. That does not imply the full game or its private source code is publicly available.
